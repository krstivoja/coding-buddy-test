# Coding Buddy Test

Sandbox WordPress plugin for exercising coding-buddy — a sandbox, not a product.

## Requirements

- WordPress 6.4+
- PHP 8.1+

## Install

Clone this repository into `wp-content/plugins/`.
Activate **Coding Buddy Test** from the Plugins screen in WordPress.

## Note

Nothing ships from here.
This plugin exists only as a test bed for coding-buddy tasks.
